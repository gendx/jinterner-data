# Test files from open data

These test files are taken from the following open data sources.

- `idfm_disruptions.json`:
  [Traffic Info Messages - Global Query](https://prim.iledefrance-mobilites.fr/en/apis/idfm-disruptions_bulk)
  API distributed by
  [Île-de-France mobilités](https://prim.iledefrance-mobilites.fr/en) under the
  [Mobility License](https://cloud.fabmob.io/s/eYWWJBdM3fQiFNm) (see
  `/licenses/2021_LicenceMobilites.pdf` in this repository). Retrieved on
  2026-11-06.
- `idfm_estimated_timetable.json`:
  [Next Departures (Île-de-France Mobilités platform) - global query](https://prim.iledefrance-mobilites.fr/en/apis/idfm-ivtr-requete_globale)
  API distributed by
  [Île-de-France mobilités](https://prim.iledefrance-mobilites.fr/en) under the
  [Mobility License](https://cloud.fabmob.io/s/eYWWJBdM3fQiFNm) (see
  `/licenses/2021_LicenceMobilites.pdf` in this repository). Retrieved on
  2026-11-06.
- `lime_paris_free_bike_status.json`:
  [GBFS Lime Paris](https://transport.data.gouv.fr/datasets/gbfs-paris-1) API
  referenced by the
  [French national access point to transport data](https://transport.data.gouv.fr/)
  under the
  [Open License v2.0](https://ia.numerique.gouv.fr/licence-ouverte-open-licence/)
  (see `/licenses/etalab-licence-ouverte-v2.0.pdf` and
  `/licenses/etalab-open-license-v2.0.pdf` in this repository). Retrieved on
  2026-11-06.
